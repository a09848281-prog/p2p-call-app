# Google Apps Script backend

このフォルダーにGASのソースを配置します。

## 役割

- 初回ペアリングコードの発行・検証・失効
- 登録済みAndroid端末のメタデータ管理
- 最終オンライン時刻と接続要求などの制御情報管理
- 端末の削除・再登録

映像・音声データやカメラ画像をGASに送信・保存しません。メディアはWebRTCで端末間転送します。

## セットアップ予定

1. script.google.comでApps Scriptプロジェクトを作成。
2. このフォルダーのCode.gsを貼り付ける（実装フェーズ2で追加）。
3. 必要なスクリプトプロパティを設定。
4. ウェブアプリとしてデプロイし、接続テストを行う。

注意：GitHub PagesからGAS Webアプリを直接呼び出す場合、クロスオリジン通信・リダイレクト・応答形式の実機検証が必要です。検証前に「そのまま動くAPI」として扱わないでください。
