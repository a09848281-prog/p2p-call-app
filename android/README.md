# Android companion app

Android側はHTML/CSS/JavaScriptを中心にし、Kotlinは使用しません。APKとして動かすためのAndroid連携部分はJavaで実装する方針です。

対象：Android 13

## 初回セットアップ

- iPadで発行した一回限りのペアリングQRを読み取る
- Android所有者が登録を承認する
- カメラ・マイク権限を許可する
- 通知を有効にし、ユーザー操作でライブサービスを開始する

## バックグラウンド動作

ライブ配信をユーザー操作で開始した後、Foreground Serviceによる継続を検証します。画面ロック中の新規カメラ・マイク起動や、強制停止後の遠隔再起動は保証できません。撮影・録音中はOS通知とアプリ内表示を維持し、停止操作を提供します。
